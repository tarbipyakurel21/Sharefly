# Prize strategy

Status is deliberately conservative: no sponsor category is marked verified without evidence.

| Prize | Eligibility / evidence | Missing requirements | Effort | Demo proof | Priority | Recommendation |
|---|---|---|---|---|---|---|
| Science and Discovery main track | Strong fit: reproducible graph and signal ablation | Organizer confirmation of description | Low | Combined vs single-signal result | P0 | Primary target |
| Business and Enterprise main track | Plausible university security workflow | Choose only if organizer framing is stronger | Low | Analyst review and report | P2 | Alternative, do not submit alongside primary |
| Arlequin Social Media Analysis | Architecture combines content and connectivity, but event rules unverified | Confirm sponsor category and requirements | Medium | Graph plus ablation | P1 | Secondary target if confirmed |
| Arlequin AI-Driven Forensics | Evidence, timeline, citations, human review concepts fit | Confirm category and forensic requirements | Medium | Evidence panel/report | P1 | Secondary target if confirmed |
| Best Use of MongoDB Atlas | Real adapter, persistence path, and storage tests exist | Atlas credentials and validation evidence | Low–Medium | Header shows Atlas and persisted review | P1 | Secondary target only when tested |
| Best Use of Gemini API | No Gemini code or credentials | Meaningful provider implementation and test | Medium–High | Must show real model contribution | P2 | Stretch, do not add for eligibility alone |
| Best Use of Tiger Data | No Tiger/Postgres implementation | Real time-series use and evidence | Medium | Must show measurable product value | P2 | Not pursued now |
| Amazon Practical AI | Useful deterministic analysis, but no AWS service use | Actual AWS integration and access | Medium–High | Must show agent/tool loop | P2 | Not pursued now |
| LangChain DeepAgents | No installed or verified DeepAgents usage | Real framework integration and reproducible run | Medium–High | Must show useful delegation | P2 | Not pursued now |
| Vultr / Solana / Photon / Nessie / ChatOverflow | No verified event access or meaningful implementation | Sponsor-specific evidence | Varies | No honest demo currently | P2 | Not suitable now |

Main-track recommendation: select exactly Science and Discovery after organizer confirmation. Pursue only sponsor categories for which the team can preserve code references, credentials/access evidence, tests, and a reproducible demo.
