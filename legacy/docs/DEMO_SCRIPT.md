# Two-minute demo script

**0–15s — Problem.** “Security teams receive messages one at a time. A job scam can look ordinary until several accounts reuse the same language and link within a short window.”

**15–30s — Difference.** Load the clearly labeled synthetic dataset. Point to the signal comparison: text-only, shared-link-only, and combined signals. “The detector is not asking an LLM for a verdict; it constructs relationships and preserves the exact evidence.”

**30–85s — Workflow.** Select the highest-scoring cluster. Show the graph, account/message/link nodes, timing, wording similarity, and score breakdown. Open the message pair comparison and evidence details.

**85–105s — Trust.** Show the disclaimer, limitations, source message IDs, and the review control. Mark the cluster “Escalated for investigation,” then download the Markdown report. Mention that the legitimate campus-link example remains low and is not called fraud.

**105–120s — Impact.** “PatternWitness turns noisy reports into a reviewable lead in seconds while keeping a human in control. Its contribution is the inspectable combination of semantic and relational signals.”

Demo mode is offline after the backend starts and uses only the bundled synthetic dataset.
