## Prioritization

Prioritize Gemini (high technical fit and demo value), then one data layer (MongoDB Atlas or Tiger Data), then Vultr if deployment is useful. Solana, Nessie, Photon, Deepagents, specialized datasets, hardware, and built-world/forensics tracks should be selected only when central to the product. Avoid stacking assumptions: each prize must satisfy its own rules.
