# CoStar hackathon kit: reference docs

Documentation copied from the CoStar hackathon kit: how the data models, schemas and concepts fit together (start at [index.md](index.md)).

- The data files (`*.jsonl`) and CSVs are **not** in this repo. They are large and licensed, so they stay local in `costar-hackathon-kit/` (gitignored).
- ShareFly does **not** currently call CoStar or use this data. Any use stays behind `lib/reference-spaces` until access is confirmed (see `AGENTS.md`).
- `tools/expand_records.py` expects the kit's local `data/` directory.
